## 2. Почему автоматика этого не ловит: разбор трёх охран

### 2.1 `G8` — проверяет не то направление

```
G8. Hard-texts series landing must link only to its own parts.
    Ищет: ../articles/<slug>/ внутри hard-texts/index.html
    Проверяет: не осталось ли лишних ссылок (inbound)
```

Серия «Сердце» ссылается на **6 правильных** статей из `/articles/`. Проверка
зелёная: «all 8 article links are members of the series».

Но она смотрит **только внутрь хард-текстса** и **только на `/articles/`**.
Что хаб должен вести на **24** статьи — не проверяется. Направление другое:
охрана ищет **лишнее**, а проблема в **недостающем**.

### 2.2 `G3` — проходит по построению

```
G3. every published part must exist on disk
```

Для Бытия-6 `baseUrl = /hard-texts/`, значит `explicitPath =
/hard-texts/<slug>/index.html` — **этот путь существует**. Охрана зелёная.

Но она проверяет **существование**, а не **принадлежность**. Адрес занят
чужой серией — и именно поэтому проверка проходит.

### 2.3 `G86` — порог слишком широкий

```
G86. Reading-time: drift > 20 минут → warn (не error)
```

У `yuzhnaya-shtunda` в `series.json` и в HTML **одно и то же число 20**.
Расхождение нулевое — охрана зелёная. А правда в том, что 20 минут на
790 слов — это 40 слов в минуту, в 4 раза медленнее нормы.

**G86 сравнивает два источника, которые ошибаются одинаково.** Он не
сверяется с реальным объёмом текста — то есть не может поймать дефект
в принципе.

## 3. Что это значит

| Вывод | Следствие |
|---|---|
| Охраны проверяют **наличие**, не **полноту** | 18 статей и 44 198 слов не видны |
| Охраны проверяют **существование пути**, не **принадлежность** | коллизия `/hard-texts/` не видна |
| Охраны сверяют **источник с источником**, не с **реальностью** | `readingTime` не виден |
| `PASSED` не означает «продукт полон» | нужны три новые охраны |

### 3.1 Три охраны, которые закроют зазоры

| Новая охрана | Что делает | Ловит |
|---|---|---|
| `G-SERIES-COVERAGE` | для каждой серии: все статьи с этим `series` есть в `parts` | 18 статей «Сердца» |
| `G-BASEURL-OWNERSHIP` | `baseUrl` серии не совпадает с другой серией; статьи под ним принадлежат ей | коллизия Бытие-6 |
| `G-READINGTIME-REAL` | `readingTime` сверяется с фактическим числом слов (150–230 сл/мин) | 50 статей |

Псевдокод самой ценной — первой:

```js
// G-SERIES-COVERAGE: ни одна статья не теряется
for (const [key, def] of Object.entries(series)) {
  const declared = new Set(def.parts.map(p => p.slug));
  const actual = mdxFiles
    .filter(f => frontmatter(f).series === key)
    .map(f => basename(f, '.mdx'));
  const orphans = actual.filter(s => !declared.has(s));
  if (orphans.length) R.err(`series ${key}: ${orphans.length} статей вне навигации: ${orphans}`);
}
```

Это ~12 строк и ловит **44 198 слов**.
