## Принцип

`AUDITREPO_OPERATING_MODEL.md` требует компактную матрицу по **корневым причинам**.
285 находок — это не 285 багов. Если 60 статей нарушают один критерий, в матрице
должна быть **одна** строка, а не 60.

Правило: **одна строка матрицы = один механизм починки**, а не одна статья.
