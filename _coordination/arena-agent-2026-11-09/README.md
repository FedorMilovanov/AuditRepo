## 6. Ограничения этого раунда

1. **Нет браузера** — всё, что требует живой вёрстки (клавиатура, скринридер,
   скрытость подсказки), проверено по коду и помечено как гипотеза.

   требуют специалиста; это названо прямо и не замаскировано.
