# INCOMING EVIDENCE — GBS2 Controls Unwired in SeriesArticleLayout (P1-14 / P1-15 / P1-16)

- Date: 2026-07-17
- Source repository: `FedorMilovanov/gb-is-my-strength`
- Auditor: Arena Agent
- Component: `src/layouts/SeriesArticleLayout.astro`, `js/enhancements.js`

## Finding

Historical tickets P1-14, P1-15, and P1-16 related to "GBS2 wiring" refer to the controls injected in the `SeriesArticleLayout` (used across the `baptisty-rossii` series and others) containing attributes like `data-gbs2-theme`, `data-gbs2-font`, `data-gbs2-search`, `data-gbs2-pane="toc"`, `gbs2Pct`, etc.

Wait, an earlier comment in the AuditRepo history (`arena-agent-6/2026-06-25/comments/comment-on-P1-13-P1-14.md`) challenged this, stating that `enhancements.js` *does* handle all these attributes via an event listener:
```javascript
document.addEventListener('click', function(e) {
  var t = e.target.closest('[data-gbs2-theme],[data-gbs2-search],[data-gbs2-share],[data-gbs2-font]'); ...
});
```

However, in checking `enhancements.js`, I do see it binding those click events.
But what about the dynamic UI state elements?
- `data-gbs2-pane="toc"` (P1-15) - The TOC pane `nav` is empty (`<nav class="gbs2-sheet-pane" data-gbs2-pane="toc" aria-label="Оглавление части"></nav>`). Looking at `enhancements.js`, it populates an element with ID `gbs2Toc` (`document.getElementById("gbs2Toc")`), but NOT `[data-gbs2-pane="toc"]`. In `SeriesArticleLayout.astro`, the TOC container is missing the `id="gbs2Toc"` attribute. Thus, the TOC generation fails and the pane remains empty!

- `gbs2Pct`, `gbs2Ring`, `gbs2Meta` (P1-16). In `SeriesArticleLayout.astro` (around line 140), these are written as static HTML without IDs that match `enhancements.js`. Wait! `enhancements.js` looks for `.gbs2-current`, but the layout doesn't provide the expected dynamic IDs (`gbs2Pct`, `gbs2Ring` are missing or hardcoded). Actually, looking at `SeriesArticleLayout.astro` line 140:
```html
<circle class="f" cx="22" cy="22" r="18" stroke-dasharray={`${Math.round(...)} 113`}></circle>
```
The circle is missing `id="gbs2Ring"`. The bold text `<b>{Math.round(...)}%</b>` is missing `id="gbs2Pct"`. The `<span>{currentPos} из {totalParts}</span>` is missing `id="gbs2Meta"`.

Therefore, the P1-15 and P1-16 findings are VALID DEFECTS. The HTML structure provided by `SeriesArticleLayout.astro` lacks the `id` hooks required by `enhancements.js` to update reading progress and build the mobile TOC.

## Current Exact Source Witness
At current Product head, `src/layouts/SeriesArticleLayout.astro` line 295 is:
`<nav class="gbs2-sheet-pane" data-gbs2-pane="toc" aria-label="Оглавление части"></nav>`
It lacks `id="gbs2Toc"`.

Lines 140-143 lack `id="gbs2Ring"`, `id="gbs2Pct"`, and `id="gbs2Meta"` respectively.

## Recommendation
This should be entered as a `CURRENT DEFECT`. `SeriesArticleLayout.astro` must include the proper `id` attributes (`gbs2Toc`, `gbs2Ring`, `gbs2Pct`, `gbs2Meta`) to bridge the gap with the `enhancements.js` runtime.
