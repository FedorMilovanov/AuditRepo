## 0. В чём я ошибался

Я мерил **MDX** (`src/content/articles/*.mdx`) и считал его текстом статьи.
Но у серии «Баптисты» маршруты устроены иначе:

```astro
// src/pages/baptisty-rossii/dva-sezda-1884/index.astro
import BaptistyRossiiDvaSezda1884Body from '@/components/baptisty-rossii/...Body.astro';
// MDX НЕ импортируется вообще
```

Для сравнения — обычная статья:

```astro
// src/pages/articles/anatomiya-padeniya-pyat-stadiy/index.astro
import Content, { frontmatter } from '@/content/articles/anatomiya-padeniya-pyat-stadiy.mdx';
<Content />
```

**Вывод:** у баптистов MDX **не подключены к страницам**. Читатель видит
`Body.astro`. Это не два формата одной статьи — это **два разных текста**.

## 3. Что это меняет по существу

### 3.1 Главное: у серии два текста, и они расходятся

| Проблема | Следствие |
|---|---|
| Правка в MDX **не попадёт на сайт** | редактор правит файл — читатель не видит изменений |
| Правка в Body.astro **не попадёт в MDX** | архив расходится с продуктом |
| Оба называются «статьёй» | любой аудит по MDX описывает не то, что читают |

Это не «косметика» и не «разные форматы». Это **split-brain контента** —
системная причина, из-за которой три агента (я, `c6d6c46c`, `0b6f34f6`)
получали разные числа на одном и том же якоре.

### 3.2 Что уже названо в проекте

Ветка `c6d6c46c` ссылается на существующий владелец этой проблемы:
`SYS-CONTENT-AUTHORING-PUBLICATION-CONTRACT`, и на критерий
`C23 Покрытие MDX ↔ компоненты` (HARD) у агента `0b6f34f6`.

**Мой вывод:** критерий C23 заведён верно, но **у него 0 авто-флагов** —
потому что проверяется *наличие* импорта, а не *расхождение текстов*.
Нужен замер сходства, а не проверка существования.

## 4. Предлагаемая охрана

```js
// G-MDX-ASTRO-PARITY: текст MDX и компонента не должны расходиться
// без явного решения (Jaccard по 8-словным шинглам)
for (const page of astroPages) {
  const mdx = importOf(page, /@\/content\/articles\/(.+)\.mdx/);
  if (!mdx) continue;                       // страница не на MDX — пропуск
  const body = importOf(page, /Body\.astro$/);
  if (!body) continue;
  const j = jaccardShingles(text(mdx), text(body), 8);
  if (j < 0.30) R.err(`MDX и компонент расходятся: ${page} (Jaccard ${j.toFixed(2)})`);
}
```

Для баптистов условие `importOf(mdx)` **не сработает вообще** — и это
отдельный, более простой сигнал:

```js
// G-ORPHAN-MDX: MDX-статья, на которую не ссылается ни один маршрут
const orphans = mdxFiles.filter(f => !pagesReferencing(f).length);
if (orphans.length) R.err(`MDX без маршрута: ${orphans.length}`);
```

**`G-ORPHAN-MDX` — самый дешёвый способ поймать этот класс дефекта.**
Для баптистов он показал бы 9 файлов сразу.

## 5. Ограничения этой поправки

1. Я мерил **HTML-тени в репозитории** (`baptisty-rossii/*/index.html`),
   а не собранный Astro. Числа могут отличаться от прода.
2. `w()` в моём замере вырезает JSX-выражения `{...}` — часть вставленного
   текста могла не попасть в счёт.
3. Абзацность, CV и структуру **живого слоя я не мерил** — только объём.
4. Поправка касается **серии «Баптисты»**. У остальных серий маршруты
   на MDX (проверено на `anatomiya-padeniya-pyat-stadiy`), но полную
   проверку по всем 56 маршрутам я не делал.

## 8. Уточнённая строка матрицы

Вместо двух строк — одна корневая:

| Строка | Масштаб | Приоритет |
|---|---|---|
| `GBS-MDX-ORPHAN-CONTENT` | **42 MDX из 70** не импортируются ни одним маршрутом; у 18 из них нет и навигации | **P0** |

Подчинённые (следствия, не отдельные причины):
- `GBS-SERIES-NAVIGATION-INCOMPLETE` (18) — проекция в навигации;
- `GBS-MDX-ORPHAN-BAPTISTS` (9) — частный случай;
- `GBS-CONTENT-SPLIT-BRAIN` — расхождение текстов MDX и Body (до 3,55×).

### 8.1 Охрана, которая ловит всё сразу

```js
// G-ORPHAN-MDX: MDX, на который не ссылается ни один маршрут
const referenced = new Set();
for (const p of glob('src/pages/**/index.astro')) {
  for (const m of read(p).matchAll(/@\/content\/articles\/([a-z0-9-]+)\.mdx/g))
    referenced.add(m[1]);
}
const orphans = mdxFiles.filter(f => !referenced.has(slug(f)));
if (orphans.length) R.err(`MDX без маршрута: ${orphans.length} из ${mdxFiles.length}`);
```

Одна охрана, 8 строк, ловит **42 файла**.
