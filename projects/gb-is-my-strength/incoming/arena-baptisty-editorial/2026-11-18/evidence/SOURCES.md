## 3. Локальное воспроизведение и внешние свидетельства

1. Взять исходники по Product SHA из [README](../README.md), выполнить `npm ci` под Node `22.23.4` и npm `10.9.9`. Использовать `PUBLIC_GB_GROK_HERMENEUTICS_PILOT=1` и `GB_BUILD_INSTANT=2026-11-18T10:39:11Z` (для tarball без `.git`) при `npm run strangler:build:production-like`, затем `npm run page-ownership:dist:production-like`. На первоначальной попытке системный Node не подходил Astro 7; pinned сборка сгенерировала 112 страниц, копирование прошло, postbuild без Git instant остановился. С явным instant постобработка/проверки заголовков и ownership пройдены. Повтор с явным instant достиг успешных шагов Astro, postbuild, hygiene и dist guards; ownership проверен отдельной командой. Полный CI, Pagefind и service-worker/promotion gates локально не заявлены.
2. Обслужить `dist` локальным статическим сервером с корректными MIME (`image/svg+xml` для схем), Chromium `153.0.8010.0` (@sparticuz/chromium `153.0.0`, Playwright `1.64.1`, NSS libs в sandbox), 320/390×844 и 768/1440×900. Проходил Chromium headless, не мобильный клиент пользователя и не live. В сканировании SW блокирован, внешние запросы отключены, `document.fonts.ready` и decode изображений дождались. `measurements.json` — компактная выжимка, не копия HTML или источников.
3. Чтобы повторить **обрезание**, открыть A2 на 1440 px, прокрутить до `.article-body figure img[src*="/atlas/"]`; A9 — то же на 320. Открыть сам `src` как SVG, после готовности шрифта в консоли измерить `document.documentElement.viewBox.baseVal.width` и для каждого `text` — сумму `getBBox().x + getBBox().width`. Пример A2: заголовок начинается на x≈42, конец x≈911, `viewBox` 760. A9: строка легенды x≈893 при той же границе. Проверка ширины `documentElement.scrollWidth` этого не ловит. Внутренние карточки схем требуют отдельного контроля границ текста, даже когда весь SVG проходит.
4. Для **оглавления** открыть R на 390 px, нажать нижнюю кнопку `#mobPartTocBtn`, выбрать в `#partTocOverlay` ссылку `a[href$="#what-to-search-next"]`.
