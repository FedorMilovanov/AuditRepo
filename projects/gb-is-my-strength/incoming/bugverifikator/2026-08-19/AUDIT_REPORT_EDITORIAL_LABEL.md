# Аудит-отчет: Валидация бага EDITORIAL-LABEL-INCONSISTENCY

## Контекст
- **Целевой репозиторий**: `FedorMilovanov/gb-is-my-strength`
- **Анализируемый коммит**: `cb3681e1a`

## Валидация EDITORIAL-LABEL-INCONSISTENCY
🔴 **Подтверждено (Source-confirmed)**

**Анализ кода**:
В файле глобальной навигации `src/components/ui/Header.astro` лейбл жестко задан как "Разбор заблуждений":
```html
<li><a href="/hard-texts/">Разбор заблуждений</a></li>
```

При этом в централизованном конфигурационном файле `src/data/site.ts` (`SECTION_META`) каноническое название раздела определено как "Трудные тексты":
```typescript
  'hard-texts': {
    label: 'Трудные тексты',
    url: `${SITE.url}/hard-texts/`,
```

**Вывод**: Существует прямое расхождение между глобальным источником истины (SSOT) метаданных разделов `site.ts` и хардкодом в шапке сайта `Header.astro`. Пользователь видит в меню одно название, а метаданные/внутренняя логика могут использовать другое. Баг подтвержден. Решение — использовать `SECTION_META['hard-texts'].label` внутри `Header.astro` либо синхронизировать текстовые значения вручную.
