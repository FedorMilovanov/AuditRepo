# Имена Бога — два самостоятельных визуальных флагмана v0.8

**Статус:** проверенный автономный **прототип**, не Product и не опубликованный сайт. Оригинальные Arena ZIP и предыдущий кандидат v0.7 не изменены.

- `atlas/`: светлая интерактивная Астролябия (React + Canvas 2D, 36 исторических записей).
- `sozvezdie/`: тёмное Созвездие (React + SVG/Motion, 29 исторических записей).
- `checks/browser_v08.cjs`: реальный cross-site QA (фокус, орбитальная клавиатура, reduced motion, геометрия и runtime).
- `source-manifest.json`: SHA-256 исходников с нормализацией CRLF/LF для Windows/Linux.

## Главные исправления против v0.7

1. Модальное досье Атласа передаёт фокус в статью при выборе «Перейти в статье» и возвращает его только при обычном закрытии; таймер фокусировки очищается. Статьи получили `tabIndex=-1` для программного фокуса без лишней Tab-остановки.
2. В орбитах Созвездия стрелки/Home/End теперь работают и на центральном узле ЯХВЕ, а не только на 12 остальных узлах.
3. Настройка отключения анимаций читателя управляет также программной плавной прокруткой; системная preference остаётся обязательной.

**Не менялись** данные имён, фото Синая, зависимости и визуальное направление обеих страниц. Тексты не публикационно подтверждены: Research #379 ведёт отдельный корпус.

## Проверка

Из каждой папки приложения: `npm ci && npm run build && npx tsc --noEmit`. Для Созвездия также `npm run qa`. Для дополнительного QA после сборки обоих: `CHROMIUM_PATH=/path/to/chromium node checks/browser_v08.cjs`.

Windows headless Chromium: Vite + strict TS обоих проектов PASS; полный QA Созвездия 78/78 PASS; новый v0.8 QA 38/38 PASS (320/390/768/1440px). Документальные доказательства и ограничения — `../../research/ITERATION_V08_FOCUS_ORBIT_MOTION.md`.

К следующему рубежу требуются WebKit, визуальное утверждение, производительность, права на медиаконтент, реальная Astro-интеграция, canonical reader/search/SEO и Research publication gate. Никогда не переносить React/Vite shell поверх текущего Site product runtime.
