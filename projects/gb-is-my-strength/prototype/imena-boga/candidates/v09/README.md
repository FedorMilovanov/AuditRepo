**Статус:** две автономные React/Vite лабораторные версии, не Product и не опубликованные страницы. Основание: `candidates/v08/`, оригиналы Arena и все предыдущие версии сохранены.

| Версия | Художественное направление | Технология |
|---|---|---|
| `atlas/` | Светлая Астролябия: медальон, 3D-проекция, подробный исследовательский интерфейс | React, Canvas 2D |
| `sozvezdie/` | Тёмное Созвездие: орбиты, пейзаж, большое чтение, звёздные эффекты | React, SVG, Motion, Canvas |

## Изменения относительно v0.8 (три production-source файла)

- **Atlas `SacredAstrolabeHero.tsx`:** адаптивная ширина медальона вместо жёстких минимумов; 44px стрелки остаются доступными на 320px. ResizeObserver перерисовывает неподвижный Canvas после изменения backing-store, иначе WebKit обнулял сцену.
- **Atlas `App.tsx`:** двухстрочная мобильная шапка оглавления с переносами вместо двух несжимаемых горизонтальных подписей.
- **Созвездие `Starfield.tsx`:** пауза и reduced-motion выключают RAF, **но сохраняют один статический кадр**. Корректная отрисовка после resize и входа в viewport.

Исходные данные 36+29 имён, фотография Синая и исходные Arena ZIP не изменены. Их публикационная верификация — отдельный Research #379.

## Воспроизведение

Из `atlas/` и `sozvezdie/`: `npm ci`, `npm run build`, `npx tsc --noEmit`.

Для междвижкового теста из `checks/`: `npm ci` и `npm test`. По умолчанию Playwright WebKit на размерах 320/390/768/1440; можно выбрать `ENGINE=chromium` и `CHROMIUM_PATH` установленного Chrome либо `VIEWPORTS=320,390`. `FONTS_MODE=offline` — только отдельная проверка запасной гарнитуры при недоступных внешних шрифтах; **не** визуальная сертификация оригинальных шрифтов. Версия драйвера закреплена как `playwright-core@1.62.1`.

Проверки требуют существующих бинарников браузеров, установленных в Playwright-среде (не скачиваются во время каждого теста). Продуктовый GitHub CI, WebKit на реальном iPhone, а также LCP/INP ещё не засвидетельствованы. Подробнее: `../../research/ITERATION_V09_WEBKIT_STATIC_RENDER.md`.
