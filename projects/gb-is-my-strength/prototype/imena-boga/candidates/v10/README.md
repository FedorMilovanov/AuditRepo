# Имена Бога — автономные прототипы v1.0 (раздельные ресурсы)

**Статус:** лабораторный кандидат, не Product/не публикация. Два самостоятельных флагмана: светлая Астролябия (`atlas/`) и тёмное Созвездие (`sozvezdie/`). Исходные ZIP Arena и v0.7–v0.9 сохраняются отдельно.

## Что изменено относительно v0.9

- Удалён `vite-plugin-singlefile` из Vite-config, package и lock в **обоих** проектах. Результат: стандартный Vite HTML + хешированные CSS/JS в `dist/assets` с независимым HTTP-кэшированием.
- У обоих прототипов `base: './'`: вложенные самостоятельные адреса работают без привязки к корню домена.
- В самостоятельном `sozvezdie/scripts/qa.mjs` исправлены MIME для .js/.css/.woff2, заменён конфликтующий фиксированный порт на выделяемый системой и ограничена доступная серверу директория dist.
- QA `checks/browser.cjs` теперь использует настоящий локальный HTTP и проверяет загрузку CSS, дочерних ресурсов, геометрию и неподвижные Canvas-сцены на WebKit/Chromium.
- **Само визуальное приложение, исследования и фотография Синая не изменены.** Всего изменено семь файлов конфигурации/QA в исходных проектах (три для A, четыре для B).

## Воспроизведение сборки

В каждой директории `atlas/` и `sozvezdie/`:

```bash
npm ci
npm run build
npx tsc --noEmit
```

Затем отдельно в `checks/`:

```bash
npm ci
npm test
```

По умолчанию проверяется WebKit на 320/390/768/1440 px. `ENGINE=chromium` — Chromium; `CHROMIUM_PATH` — при необходимости путь к установленному браузеру. `FONTS_MODE=offline` блокирует только сторонние домены шрифтов для отдельного fallback-теста; это **не** визуальная сертификация оригинальной гарнитуры.

Из `sozvezdie/` дополнительно выполняется `npm run qa` (78 сценариев; Chromium).

## Важные пределы

- Это не уменьшение JS на порядки: обоим Vite-проектам ещё предстоит выборочное выделение тяжёлых интерфейсов и Astro Islands. Оба bundle предупреждают о JS chunks порядка 500KB до сжатия. **Нельзя заглушать warning лимитом.**
- В HTML-прототипах пока есть внешние Google Fonts CSS. При недоступности сервиса измерение online-font загрузки бывает нестабильно. В существующем Product `gb-is-my-strength` уже имеется локальный фонд Cormorant/Inter/Lora/Noto/Playfair, но некоторые семьи Созвездия (EB Garamond/Frank Ruhl Libre) требуют проверки лицензий, соответствия и согласования с Product; шрифты в этот кандидат не копировались.
- Нужны замеры LCP/CLS/INP и слабых телефонов, визуальное принятие обоих направлений, реальные Safari iOS и editorial gate Research #379.
- Product `gb-is-my-strength` использует Astro (локально наблюдалось 7.2.9) + React. **Весь сайт в React переписывать не нужно.** Перенос только через Product-owned маршруты, islands, Reader/Search/SEO; лабораторный Vite shell не становится Product app.
