# Имена Бога — два самостоятельных прототипа v1.1

**Назначение:** премиальные автономные визуальные эталоны Астролябии (Canvas/React) и Созвездия (SVG/Motion/React). Это лабораторный код AuditRepo, **не опубликованный Product**.

## Отличия от v1.0

Астролябия:
- Полное досье `DivineNameModal` вынесено в отдельный динамический JS-чанк, загружаемый только при открытии имени или прямой ссылке на него.
- `TheologicalQuiz` загружается только при приближении к разделу (IntersectionObserver, `rootMargin=1600px`), при отсутствии поддержки API компонент включается штатно.
- `NearViewport` после первого входа в область не размонтирует модуль; настройки и фокус не пропадают.
- `FeatureLoadBoundary` изолирует ошибки загрузки интерактивных модулей: основная статья остаётся доступной, пользователь видит явную команду повторной загрузки.

Созвездие:
- `MobileIndex` загружается отдельно после входа в режим чтения статьи (`inArticle`), не при старте.
- Изолирована ошибка загрузки мобильного указателя: статья остаётся доступной.

Общие данные 36+29 имён, фото Синая и оригинальные ZIP Arena **не изменены**. Research #379 самостоятельно ведёт корпус. Артефакты предыдущих v07–v10 остаются сохранёнными.

**Оговорка по результатам:** начальный основной JS Астролябии действительно уменьшился на 5,76 КБ gzip. В Созвездии основной gzip, напротив, вырос на 0,15 КБ: изменение лишь разделяет доставку мобильного UI и ещё не подтверждено как выигрыш производительности. Общий объём кода после открытия всех компонентов не уменьшился, а число запросов увеличилось. Vite по-прежнему предупреждает о главном чанке Созвездия больше 500 КБ; лимит предупреждения не повышен.

## Проверенные процедуры

Оба приложения: `npm ci`, `npm run build`, `npx tsc --noEmit` — PASS.

Из `checks/` выполнить `npm ci`, затем:
- `npm test`: WebKit 320/390/768/1440px и два приложения; `ENGINE=chromium` для Chrome, `FONTS_MODE=offline` для проверяемой резервной типографики;
- `npm run qa:lazy`: пять проверок реальных сетевых запросов, фокуса и открытия модулей;
- `npm run qa:failure`: три принудительных отказа доставки JS, проверка сохранения страницы.

Отдельно в `sozvezdie/`: `CHROMIUM_PATH=<Chrome> npm run qa` — 78/78 PASS.

Итоговые лабораторные проверки: **WebKit 8/8, Chromium 8/8, отложенная загрузка 5/5, ошибки сети 3/3, исходный полный браузерный QA Созвездия 78/78**. Браузерное доказательство относится к standalone Vite, не к будущему Astro/Product.
