# Имена Бога — два премиальных визуальных прототипа v1.2

**Статус:** лабораторные React/Vite-эталоны для будущей интеграции в Astro `gb-is-my-strength`. Не публикация и не замена работающего сайта.

## Что изменено после измерений v1.0/v1.1

**Астролябия:** возврат основного досье `DivineNameModal` в стартовый JS. Условная загрузка увеличивала медиану первого открытия с 691 до 931 мс в первом четырёхкратном испытании; при повторном сопоставлении v1.0 и v1.2 медианы составили 318 и 335 мс (другая сессия, различия незначимы). Досье больше не делает отдельный сетевой запрос. Только второстепенный `TheologicalQuiz` остаётся ленивым, с IntersectionObserver и локальной ErrorBoundary.

**Созвездие:** восстановлен немедленно доступный `MobileIndex`; его вынос ранее почти не давал выигрыша для стартовой загрузки. Исторический JPEG Синая **сохранён**; добавлен WebP (1672×941, ImageMagick q85, 140 842 Б вместо JPEG 216 480 Б) через семантический `<picture>` с JPEG fallback. PSNR относительно исходного JPEG ≈ 40,67 дБ. Не утверждать право публикации: право использования изображения всё ещё требует проверки.

Изменения v1.2 не затрагивают `divineNames.ts`, `names.ts` и исходный JPEG. Оригиналы Arena, v07–v11 сохраняются раздельно.

## Как проверить

В `atlas/` и `sozvezdie/`: `npm ci && npm run build && npx tsc --noEmit`. Затем в `checks/` выполнить `npm ci` и:

- `npm test` с `ENGINE=webkit` или `ENGINE=chromium`; `FONTS_MODE=offline` (fallback без внешнего Google Fonts); ширины 320/390/768/1440.
- `npm run qa:delivery` — 5 проверок основного и второстепенного кода, клавиатуры и диалогов.
- `npm run qa:failure` — 1 сетевой отказ второстепенного Quiz без потери статьи.
- `npm run qa:image` — проверка WebP по HTTP, декодирования и геометрии Chromium/WebKit.
- В `sozvezdie/`: `CHROMIUM_PATH=<path> npm run qa` — исходные 78 сценариев.

Результаты Windows: Vite + TypeScript PASS для обоих; WebKit 8/8, Chromium 8/8, delivery 5/5, quiz failure 1/1, WebP decode 4/4 и полный QA Созвездия 78/78 — PASS.
