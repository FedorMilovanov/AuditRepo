## Что лучше в каноническом первом экспорте

| Область | Второй экспорт | Уже импортированный канонический HOREB |
|---|---|---|
| Непрерывный маршрут у обрыва | Ступенчатая коллизия `inChasmZone`; возможен резкий горизонтальный скачок при входе | Совместная плавная функция `chasmFactor` для геометрии и collision, тест осевого маршрута и отсутствия скачка |
| Некорректные координаты | Нет явной защиты `constrain` от NaN/Infinity | Fail-closed при нечисловых координатах |
| Настройки из localStorage | Обобщённое небезопасное смешивание JSON в дефолты | Проверка типов/диапазонов; восстановление невалидного прогресса |
| Жизненный цикл World | Нет отмены `World.create` во время загрузки шрифтов | `AbortSignal` и игнорирование отменённой инициализации |
| Мобильный интерфейс у святого порога | Панель и кнопки могут перекрывать управление при узких ширинах | Компактное меню и перемещение панели; прошлый Chromium mobile-emulation witness |
| Без-JS доступность | Только `noscript` с сообщением | Генератор `tests/generate-reader.mjs` + отдельный `public/reader.html` с 25 досье/RTL/ссылками, без JS |
| Регрессии | 20 unit tests | 24 unit tests + `tests/regression.mjs` для mobile, storage и входов |
| Репозиторный handoff `data/exhibits.ts` | Вторая 30-KB копия реестра, риск расхождения | 129-byte реэкспорт на один канонический typed registry |

Первый архив также содержит дополнительные `public/reader.html`, `tests/generate-reader.mjs`, `tests/regression.mjs`, отсутствующие во втором.

## Решение для внедрения

**Переносить из второго экспорта нечего, что было бы подтверждённым улучшением.** Не заменять ни `HorebApp.tsx`, ни `nav.ts`, ни `World.ts`, ни 3D-геометрию этим вариантом. В частности, **не копировать** дублирующий `data/exhibits.ts` в корень.

Открытый следующий инженерный объём определяется самостоятельной спецификацией `briefs/SCENE_SPEC_42.md`: развитие **существующего** 3D-кода до 42 исторически отличимых интерактивных контекстов, без визуального изображения Бога; проведение clean npm build, Chromium/WebKit/mobile+GPU performance QA и редакционной сверки с Research #379. Текущее содержимое обоих архивов **не** удовлетворяет требованию 42 полноценных сцен.

**Не путать:** это сравнительный source audit, а не owner visual approval, не готовность к Product и не разрешение на merge/deploy.
