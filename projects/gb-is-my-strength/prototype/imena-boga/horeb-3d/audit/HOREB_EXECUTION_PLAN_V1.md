## 4. Премиальная метрика качества / dashboard
Каждый из 42 ID получает 6 осей, 0–5: **оригинал/источник** (входной gate), **смысл категории**, **дальняя читаемость**, **сценическая уникальность**, **осмысленное действие**, **аудио/доступность**. Показать не одно усреднение: **никаких усредняющих «100% top»**, если любой hard gate красный. Снимки на равных расстояниях 24/12/4м, уникальный slug, 3 viewport, video 30s и реальная ручная проверка каждого RTL-глифа. Целевое `>=4/5` по 5 художественным осям при source gate PASS.

## 5. Богословская граница и ангельские появления
- Ни видимый Бог, ни Его актёрское говорение от первого лица, ни «светящаяся фигура Бога». Ветхий днями (Дан. 7), Исх. 3 и видения Исаии **не** визуализируются как видимый персонаж Бога.
- Ангельские существа **не дефолтные NPC**. Только 1–2 отдельно утверждённых эпизода с явным библейским референтом (например Исх. 3:2 или Ис. 6:2–3), с локаторами и демонстрацией как **условного художественного решения**, не «исторического вида». По умолчанию: свет/тень/поэтическое впечатление без сущности. Никакой механики «появился ангел — получил баллы».
- По тетраграмматону визуальный знак `יהוה` только как **текст цитаты/экспозиции**, не физическое проявление Бога и не «магическая руна». Спорные чтения — в source note, не произносятся автоматически.
