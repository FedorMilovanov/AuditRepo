# HOREB 3D — 42-сценная матрица режиссуры, интерактива и закадрового текста (V1)
Дата: 2026-11-08 · статусы всех записей **HOLD** · исходный `exhibits.ts` из PR #543 на `2e266dba`.

**Важно:** это **42 исследовательских обозначения** (29+13), не 42 личных имени Бога, не 42 независимых загрузочных уровня. Зоны 0 и 6 — пролог/узкий проход без новых записей; зона 7 — 2 отдельных текстовых момента у одного куста. Приведённые действия, лучи, саунд-реплики — **предложения к реализации**; в текущем коде они не все работают. Тексты диктора — оригинальные художественные **рабочие черновики, не согласованная озвучка**.

## Легенда
- H — 7 эталонных сцен Wave D + финальный второй текст у того же куста; M — следующая волна; L — камерные/сравнительные.
- Колонки взяты из настоящего typed-registry (`id`, `zone`, `displayLabelRu`, `category`, `originalUnicode`, `verseReference`). Визуал/действие/voice cue — авторские проектные дополнения.
- Голос **наблюдателя-экскурсовода**, никогда голос Бога. После проверки произношения: отдельно можно записать короткую оригинальную форму; по умолчанию русское название и контекст. TTS/непроверенная вокализация неприемлемы для релиза.
- Русский знак `ЯХВЕ` в редакционных названиях — ярлык, а не разрешение произносить тетраграмматон выбранной гипотетической вокализацией. Для английского/греческого/арамейского не рисовать еврейские буквы.

## Матрица сцено-логики (обязательно для каждого `id`)
**`unseen → noticed → listening_opt_in → inspecting → context_opened → revisitable`**; это НЕ RPG progression. У игрока есть **прямой выход** в текст и отказ от звука, сохранение не блокируется «правильным ответом». Для medium/low допустимы 1 meaningful action + A/B-сравнение; для Hero — 2 отдельных осмысленных действия.

Глобальные триггеры: дальний 24–18 м — один световой опорный знак с лингвистически проверенной формой; 14–8 м — сцена и категория/мягкая пульсация по запросу; ближний 5–2 м — интерактив и отрывок со ссылкой. У `bush-scene` ближние условия подчиняются `R_OUTER=14`, `R_INNER=6.5`: **никаких действий по обходу защитных границ**. Для имён латиницы/греч./арамейского — именно их исходное письмо, а не иврит.

## Гейты точности перед запуском голоса или светящегося текста
1. **Графемы / RTL и источник:** сверка с `Research #379`, verse locator, язык, статус. Ошибка `el-elyon` (**ם/ן**) уже исправлена в HOREB по Research #379 `verifiedForm=אֵל עֶלְיוֹן` с unit-защитой. Остальные 41 записи и произношения требуют полного поштучного review, общий публикационный HOLD сохранён.
2. **Разделение похожих форм:** `el-roi` Рאה «видеть» против `ro-i` רעה «пасти»; `ehyeh` (3:14) и `yhwh` (3:15) — два разных текста; `tsidkenu` в Иер. 23:6 и 33:16 имеет разных референтов; `shammah` — город; `yireh` — место; `nissi`, `shalom` — жертвенники.
3. **Не весь каталог — иврит:** `elah-shmaya`, `atiq-yomin` — арамейский; `abba`, `pantokrator`, `alpha-omega`, `ego-eimi`, `kyrios-ho-theos` и др. — письменный греческий NT. Звучание каждого слова нуждается в фонетической карточке.
4. **Жанр/онтология:** видение, поэзия, реальный топоним, название жертвенника, Иисусова речь — разная композиция; никакого «все 42=имена Бога» и художественного Бога-аватара.
5. **Опциональное явление ангелов:** только по отдельно разрешённому `source-reference + depiction note + editor approval` там, где библейский текст действительно упоминает ангела/серафимов; по умолчанию ни один angel NPC не появляется.
6. **Право/редактура:** короткие звуковые paraphrase, не длинное чтение непроверенного лицензированного текста; `HOLD` до research & rights PASS.
