# HOREB 3D — закадровый голос, пространственный звук и сценарий запуска (V1)
Дата: 2026-11-08 · статус **PENDING SCRIPT/PHONETIC/RIGHTS APPROVAL — НЕ СОЗДАННЫЕ АУДИОФАЙЛЫ**. Связано с [планом W0–W10](./HOREB_EXECUTION_PLAN_V1.md) и [матрицей 42 сцен](./HOREB_SCENE_MATRIX_42_V1.md).

## 1. Художественный тезис
**Голос не изображает Бога и не говорит от Его лица.** Это человеческий, благоговейный **внешний рассказчик**: взрослый низкий баритон с ровной естественной артикуляцией, сильной грудной опорой без хриплого «трейлерного рыка». Спокойный русский; паузы осмысленные; без псевдовосточного акцента, ложного пророческого экстаза, ангельских «сообщений» или имитации реального пастора/актёра. По умолчанию — **мужской голос, речь в русском пересказе**, не автоматически генерируемая «голос Бога» драма.

Цель: на 3–4 предложения пользователь слышит не «начало квеста», а приглашение увидеть библейское свидетельство. **Суть, не громкость:** плотное, близкое человеческое чтение, после которого естественное пространство отвечает мягким отражением. Ночной Хорив темен: звук куста должен дополнять, а не превращать огонь в громогласный источник «голоса Бога».

## 2. Что есть и что отсутствует в коде
- Уже есть `src/.../engine/audio.ts`: `AmbientAudio` с Web Audio шумом ветра, огня, капель, шагов, suspend/resume и `sound` toggle.
- **Не существует:** утверждённой записи человеческого диктора, phonetics registry, `NarrationDirector`, `ConvolverNode`-профилей, `PannerNode` для смысловых объектов, optional captions, cue-state / subtitle timing, attributions / audio licenses. Внедрение только отдельными коммитами после source gate.
- Никакого `SpeechSynthesis` как основы релиза: системные русские/еврейские/греческие голоса и произношение непредсказуемы; можно рассмотреть лишь временный локальный технический fallback с явной меткой и выключенным по умолчанию звуком.

## 3. Три пространственных профиля — реальные стартовые гипотезы, НЕ измеренные параметры сцены
| Профиль | Смысл | Сигнал dry/wet / хвост IR | Защита от искусственности |
|---|---|---|---|
| **CAVE_STONE** (зоны 1–4) | Каменные залы отражают человеческий голос | dry ~80%, wet ~20%, раннее отражение ~45–90 мс, IR ~1.9–2.6 с | Не превращать речь в неразборчивый соборный гул; без тройного копирования «Яхве...» |
| **PASSAGE** (5–6) | Узкий путь/галерея | dry ~85%, wet ~15%, IR ~0.9–1.4 с | Убывающий шум, сохранение четкости согласных |
| **OPEN_HOREB** (7) | Открытое пространство и близкий куст | dry ~95%, wet ~5%, короткая отражённость ~0.3–0.7 с + атмосферная пауза | **НЕ** подавать голос из куста через 3D Panner (не создаём «Бог заговорил»), без громкого магического эха |

Это начальные значения для A/B-прослушивания на акустике и наушниках. Завершённость — **проверенная разборчивость**, а не наличие реверба.

### DSP-цепочка
`licensed dry narration PCM → per-cue gain + highpass (80 Hz) → gentle compressor → dry send + filtered wet send through ConvolverNode(IR) → speechLimiter → voiceBus → master`.

- Пространственные независимые вещи (вода, ветер, шаги, треск) при необходимости через `PannerNode` с distance model; диктор обычно закреплён в «невидимой аудиопозиции слушателя», не в кусте.
- Запись 48 kHz / 24-bit mono WAV dry, без шумоподавления, уничтожающего окончания слов; мягкие вдохи допустимы, речевые паузы записываются с естественной динамикой.
- Начальная цель сведения для экспорта: stereo **≈−16 LUFS integrated**, **true peak ≤−1 dBTP** (записывать реальную проверку лимитером/измерителем). У очень коротких отдельных реплик LUFS нестабилен: замерять пакет и слушать на мобильном.
- During narration: duck окружающей среды **~−7 dB** с плавным входом 250 мс и восстановлением 650 мс; необязательный low-pass ambience. Никогда не увеличивать master ради «величия».
- Намного важнее различимость `х`/`г`/шипящих и собственных имён, чем глубокая басовая окраска. Без искусственного смещения высоты голоса >1 полутона.
- Источники IR/аудио — записанные собственноручно или с ясным разрешением и SHA/license; никаких неизвестных «кинематографических» библиотек.

## 4. События, ограничения и UX
| Условие | Действие | Защитное поведение |
|---|---|---|
| Нажатие **«Начать путешествие со звуком»** | Пользовательским жестом создать/resume `AudioContext`, предложить «Голос: вкл/выкл» | По умолчанию нет неожиданного autoplay; если отказ — тишина и субтитры доступны |
| ID впервые в фокусе **12–8 м** в течение >=1.2 с и голос включён | 1 короткая реплика категории/контекста (если `pronunciationStatus=approved`) | Не говорить, если речь уже идет; 45–60 с per-ID cooldown; retrigger только вручную |
| Игрок нажал **«Слушать»** в карточке | Полная 15–28 с запись об эпизоде, subtitle follow along | Ручное повторение допустимо, иная фраза прерывается плавно (crossfade 150–300 мс) |
| Открыт `role=dialog`, потеряны вкладка / контекст / звук выключен | `pause`/fade, сохранить position/timecode | Возобновлять **только по действию пользователя** после возвращения |
| Снятие обуви у Хорива | Природный звук стихает, анонс только в повествовательном тексте/субтитрах | Ни один голос не «повелевает от лица Бога»; нет звука-кнопки как «божественной команды» |
| Уход от имени >16 м | Окончить активный ambience duck, не запускать новый голос каждую секунду | Нет одновременного воспроизведения двух имён |
| Reduced motion / screen reader / mobile | Субтитры и надписи доступны без WebGL | Все действия доступны keyboard/touch; у пользователя отдельная настройка громкости диктора |

Состояние `NarrationState = idle | armed | playing | paused | completed | cancelled`. Переходы детерминированы; события типа `VOICE_READY`, `VOICE_ERROR`, `AUDIO_USER_GESTURE`, `ZONE_EXIT`, `DIALOG_OPEN`; не использовать `useEffect` React для запуска звука на каждом кадре. Исключить `setInterval`-спам и race при смене зоны.

### Data contract (проектный, не внедрён)
```ts
interface NarrationCue {
  exhibitId: string;
  category: string;               // from canonical Research registry
  ruText: string;                 // original reviewed narration
  displayOriginal: string;        // exact graphemes (do not normalize silently)
  pronunciationGuide?: string;    // reviewed by Hebrew/Aramaic/Greek consultant
  pronunciationStatus: 'HOLD' | 'approved' | 'not-applicable';
  audioAssetPath?: string;        // absent until owned recording exists
  transcriptPath: string;
  irProfile: 'CAVE_STONE' | 'PASSAGE' | 'OPEN_HOREB';
  sourceReference: string;
  editorApproved: boolean;
  rightsApproved: boolean;
}
```
Never infer pronunciations from `transliteration` or hardcoded `SpeechSynthesis`; no audio playback until `editorApproved && rightsApproved && pronunciationStatus` appropriate. For `yhwh`, default audio is a **Russian circumlocution**, not invented reconstructed pronunciation.

## 5. Готовые сценарии человеческого голоса — **оригинальные черновики для записи**, не цитаты Писания

### VO-00. Пролог / 0
- Trigger: пользователь выбрал режим «Со звуком» и вошёл на 3D-путь; **один раз**.
- Cue: [ветер вдали, 1.2 с тишины] «Перед вами — путь через библейские свидетельства. Здесь встречаются Божьи имена, титулы, метафоры и названия памятных мест. Каждое слово имеет свой контекст. Не спешите. Сначала смотрите. Затем открывайте Писание.» [тишина 1.5 с].
- Не говорить «это подлинная пещера/гора с собранными событиями всех эпох». Художественная экспозиция должна обозначаться как таковая.

### VO-01. `elohim` / Быт. 1:1
- Trigger: зритель раскрыл каменный горизонт.
- [dry close → stone reverb] «Элохим. Так начинается повествование Бытия. Мир открывается перед человеком не как случайная сцена, а как свидетельство о Творце. Взгляните на горизонт. А затем прочитайте первую строку Писания.» [3 с пространственной паузы].
- Фон: глубокий ветер, без искусственного звука создания Вселенной. Нет божественной фигуры.

### VO-02. `el-shaddai` / Быт. 17, 28, 35
- Trigger: открыто первое окно шатра патриархов.
- «Эль Шаддай. Это выражение проходит через историю Авраама, Исаака и Иакова. Традиционный русский перевод говорит о Всемогущем, но происхождение самого слова продолжает обсуждаться. Посмотрите, кто произносит его в каждом из трёх эпизодов.»
- Защита: **никакой** уверенной этимологии `שַׁדַּי`; произношение `Эль Шаддай` черновое до утверждения.

### VO-03. `el-olam` / Быт. 21:25–33
- Trigger: игрок исследовал колодец и выбрал дерево.
- «Эль Олам — Бог вечный. В Вирсавии Авраам вспоминается рядом с колодцем и посаженным тамариском. Здесь повествование отмечает призывание имени Господа. Откройте стих и посмотрите, что действительно сказано о дереве.»
- Защита: **НЕ** источник Агари, никаких выдуманных археологических координат.

### VO-04. `el-roi` / Быт. 16:13–14
- Trigger: зритель нашел источник; запись включается по нажатию «Слушать».
- «Эль Рои. Среди пустынной тишины Агарь обращается к Богу, Который видит. Не путайте это выражение со словами псалма о Господе-Пастыре: в еврейском тексте здесь другой корень. Откройте сначала слова Агари, затем — имя источника.»
- Защита: семантика/синтаксис `אֵל רֳאִי` отмечены как **disputed**; русская реплика после проверки редактора.

### VO-05. `yireh` / Быт. 22:14
- Trigger: прочитан стишок о месте на склоне, без «найди жертву».
- «Авраам дал этому месту название, связанное со словами: Господь усмотрит. Здесь важен не таинственный предмет и не выдуманный обряд, а свидетельство самого библейского повествования. Откройте четырнадцатый стих двадцать второй главы Бытия.»
- Защита: обозначать **место**, а не «пятое личное имя»; без сцены жертвоприношения ребёнка.

### VO-06. `ehyeh` / Исх. 3:14
- Trigger: человек стоит **снаружи** порога без обуви, открыл смысловую карточку Исх. 3:14.
- [ветер стихает; голос сухой, близкий, не из куста] «Перед нами рассказ о несгорающем кусте. Моисей встречает повеление снять обувь и вопрос об имени. В четырнадцатом стихе звучит особое самоназвание. Его смысл переводили по-разному. Откройте текст прежде, чем делать вывод.»
- Защита: не читать русское `«Я есмь…»` будто диктор — Бог; не объявлять `ehyeh` тождественным `yhwh`.

### VO-07. `yhwh` / Исх. 3:15
- Trigger: человек босиком у **разрешённой границы >=6.5 м**, вручную выбрал второй контекст.
- [ПОЛНАЯ тишина 2–3 с; голос без реверба, не в центре огня] «В следующем стихе Писание приводит Имя, записанное четырьмя еврейскими буквами. Оно связано с Богом отцов, с памятью и заветом. Прочитайте сам текст. А вопросы традиционного чтения и произношения откройте отдельно.» [тишина].
- Защита: **не произносить `יהוה` спорной реконструкцией**, не делать «голос Бога». На экране исходная форма только как текст цитаты/экспозиции.

### VO-08. `abba` / Мк. 14:36, Рим. 8:15, Гал. 4:6
- Trigger: игрок остановился у пустого молитвенного места.
- «Авва, Отче. Это обращение соединяет молитву в Евангелии с последующими апостольскими текстами. Сравните, кто и в каком контексте произносит эти слова. Библия здесь говорит больше, чем одна атмосферная декорация.»
- Защита: не озвучивать от лица Иисуса, не представлять мизансцену как документальную съёмку.

### VO-09. `sabaoth` / 1 Цар. 1:3; Ис. 6:3
- Trigger: игрок переключил две текстовые перспективы.
- «Саваоф. Господь воинств. Это выражение появляется в повествовании и в пророческом видении. Не пытайтесь построить Его образ: прочитайте, как само Писание описывает святость и величие.»
- Защита: **никакой** имитации «ангельского хора» по умолчанию. Визуальная адаптация серафимов — отдельный религиозный и арт-допуск.

### VO-10. Узкий выход / 6
- Trigger: путь возвращается к тишине, не новый Research ID.
- «Вы услышали разные слова и увидели разные свидетельства. Но слово не становится достоверным от того, насколько ярко оно сияет. Впереди — Хорив. Продолжайте путь в тишине.»
- Фон сходит на нет. Не читать название куста заранее, не активировать квест на «очки».

## 6. Произношения: hard gate (обязателен)
Таблица `pronunciation_approval` для каждого ID: `originalUnicode`, `BCP47 language` (`he`/`arc`/`grc`), `traditionalRu`, `IPA_or_russian_pronunciation`, `linguist`, `source`, `reviewed_on`, `decision`. Без этого — **RU narration only**, без декламации спорной «оригинальной формы».

- `el-elyon`: запись текущего registry `אֵל עֶלְיוֹם` конфликтует с Быт. 14:18 `עֶלְיוֹן`. До сверки с Research **не генерировать voice и крупные буквы** для этой формы.
- `el-roi` и `ro-i`: разные корни «видеть» / «пасти», не одинаковая звуковая метка.
- `ehyeh` и `yhwh`: различия Исх. 3:14/15. Тетраграмматон по умолчанию **не произносить реконструированно**; только объяснить чтение, а не навязать.
- `atiq-yomin` и `elah-shmaya`: **арамейский**, не иврит. `abba` записано греческими буквами в NT; `pantokrator`, `alpha-omega`, `ego-eimi` и пр. — греческие формулы.
- Ни одна фраза не должна сказать «Бог говорит тебе сейчас…» или объявить невидимое художественное событие реально произошедшим.

## 7. CI и аппаратная приёмка голоса
1. **unit**: no-autoplay, 42 cue IDs (= ledger), `HOLD` blocks unapproved source/pronunciation, no duplicate queued item, debounce 60 s, cancel/suspend on dialog, zone exit, visibility, route change; captions same words as voice. 
2. **browser (Chrome real)**: после click стартует звук по разрешению, mute/volume works, clicking `E` while playing does not create 2 voices, hidden tab suspends, no sound on return until explicit action, ambient duck restored even on error.
3. **physical hardware**: desktop speakers, wired headphones, phone speakers, Bluetooth with latency; user controls spoken cue volume; measured CPU/memory/DRM; no overdrive/clipping; voice remains comprehensible even with wet path muted.
4. **source**: raw voice files, SHA, recording performer permission, IR provenance/rights, edited text approvals, captions and cue-text version; no transcription generated from unknown commercial recording.
5. **art director**: A/B dry/wet in 3 profiles + no speech at all; listening panel 3–5 reviewers; no unrequested scary sounds/claim of divine voice. **Нет аудиоартефактов в PR, пока recording/provenance не готовы.**
