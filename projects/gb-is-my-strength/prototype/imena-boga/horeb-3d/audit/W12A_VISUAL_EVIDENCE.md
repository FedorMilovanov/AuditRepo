# W12A visual evidence additions

The W12A household is an independently rendered Three.js scene, not another
camera position in the well. Successful GitHub QA now MUST collect and upload
three truthful Chromium-rendered `homestead-*.png` images: initial elevated
shot, walking eye level, and 390px mobile. File size and true PNG signatures
are checked after Browser Chapters and homestead walk tests complete.
The existing Midian well and eight-zone Horeb witnesses remain mandatory.

If these images cannot be produced, CI fails instead of claiming a complete
interactive 3D world. ART acceptance additionally requires real review of
actual geometry, terrain, tent material, horizon, controls and proportions;
GLB/texture quality, people, animals and real-device performance are not done.
