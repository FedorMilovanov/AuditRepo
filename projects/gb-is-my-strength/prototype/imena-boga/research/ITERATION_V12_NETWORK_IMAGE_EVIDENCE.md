**Дата:** 2026-11-07. **Ветка:** AuditRepo PR #538 (лабораторный кандидат). Исходные опорные версии: `candidates/v10` и `candidates/v11` (git head на исходниках v11: `9beb3ae189c9f5c8ff28766d8fe4ce478826b754`). Product `gb-is-my-strength` и независимый Research PR #379 не менялись.

## Постановка лабораторного сравнения

На Windows использован установленный Chrome/Playwright; каждый прогон — новый browser context со сброшенным cache, viewport 390×844, CDP CPU throttling ×4, заданные для CDP 150 ms RTT / 200000 B/s download / 80000 B/s upload, локальный HTTP сервер, gzip с level 6, no-store. Внешний CSS Google Fonts **отключён во всех вариантах**. Сессии v10/v11/v12 чередовались; 3 прогона/версию/флагман. Отчёт включает полный JSON исходных 18 наблюдений.

Сервер localhost и DevTools emulation **не равно** реально слабый телефон и реальная мобильная сеть: responseStart обычно 3–6 мс, свидетельствуя, что loopback TTFB не имитирует удалённый сервер. Не выдавать этот тест за Lighthouse или полевой INP/LCP. LCP observer в кратком сеансе дал то же время, что FCP; эти значения не заменяют реальный измеренный LCP. CLS=0 только в наблюдённом коротком окне, а не гарантия отсутствия сдвигов после взаимодействий.

## Взаимодействие: почему отложенный основной Modal отменён

При первом четырёхкратном тесте клик→видимый диалог и передача фокуса:
- A v10: медиана 691 мс.
- A v11 с `React.lazy` для основного досье: 931 мс, сетевой запрос отдельного JS для каждого нового клиента.
- Дополнительная независимая сессия A v10 vs v12 (первый Modal снова eager): 318 vs 335 мс, оба без дополнительного JS; сравнивать между двумя сессиями абсолютное время некорректно.

**Решение:** модальное досье — основное действие, поэтому его JS должен быть готов сразу. Quiz — второстепенное нижнее содержание; его можно загружать при приближении к разделу с уже протестированной ErrorBoundary. У B MobileIndex вынос в отдельный чанк давал +185 bytes начального трафика без измеримого выигрыша FCP; восстановлен штатный eager-код, удалена ненужная компонентная граница.

## Sinai: качество, изображение и fallback

Исходный JPEG: **216 480 Б, 1672×941 RGB**. ImageMagick 7.1.2-21 WebP q85 (`magick sinai-dawn.jpg -quality 85 -define webp:method=6 sinai-dawn.webp`) — **140 842 Б**, минус 75 638 Б (-34,94%); PSNR через ImageMagick `compare -metric PSNR` — 40,6711 дБ относительно декодированного JPEG. Изменено только кодирование; исходник полностью сохранён.

Компонент `Hero.tsx` использует `<picture><source type="image/webp" .../><img src="...jpg" fetchPriority="high".../></picture>`; в WebKit и Chromium по HTTP проверены `currentSrc=.webp`, `naturalWidth=1672`, `naturalHeight=941`, код ответа 200 на 390 и 1440 px. Не подменять fallback утверждением, что браузер автоматически переключится при отказе сети WebP: JPEG здесь предназначен для браузеров без поддержки формата.

**Правовая оговорка:** наличие изображения в ZIP Arena не доказывает право размещения на сайте; перед Production обязательно подтверждение происхождения и лицензии.
