# Лаборатория правой панели «На полях»

**Статус:** разработческий прототип, не подключён к маршрутам сайта и не публикуется в production.

## Зачем этот архив

Здесь сохранена интерактивная лаборатория (43 визуальных состояния, генератор, данные для предпросмотра и автоматический аудит), чтобы следующий агент мог изучить работу и подготовить интеграцию отдельно.

Важно: текущая лаборатория демонстрирует собственную оболочку чтения и поэтому **не является готовым способом встраивания в сайт**. При интеграции следует оставить родные страницу, статью, меню/оглавление, левый рельс и мобильную навигацию без изменений и перенести только правую панель. Не подключать `shell.template.html`, `.lab-shell`, `.lab-left`, `.lab-center` или `.lab-mobile-bar` к рабочим страницам.

## Сохранение и публикация

Архив хранится в `prototypes/study-panel-lab/` разработческой ветки `arena/c99edce5-gb-is-my-strength`. Он не импортируется продуктовым кодом. Pages workflow проекта запускается при push в `main`; push этой ветки не публикует сайт. Не мержить и не переносить код в рабочие маршруты без отдельного согласования.

В исходниках остаются ссылки на реальные файлы текущего checkout, а не новые копии исходных страниц. `build.mjs` ищет корень репозитория вверх от своей папки; при запуске из отдельного каталога задайте `GB_SOURCE_ROOT=/path/to/gb-is-my-strength`.

## Локальный запуск

Из корня репозитория:

```bash
cd prototypes/study-panel-lab
npm ci --no-audit --no-fund
npm run build
npm start
```

Открыть `/` на локальном сервере. Для контрактной проверки при работающем сервере:

```bash
npm run audit
npm run capture
```

`audit`/`capture` используют Puppeteer и Chromium. `node_modules/`, построенный `index.html`, а также восстановимые `data/` и `vendor/` намеренно не входят в Git: `npm run build` создаёт их заново из проверяемых исходников репозитория.

## Передача следующему агенту

- `STATUS.md` — состояние и проверенные ограничения.
- `screenshots/gallery.html` — галерея 43 состояний.
- `screenshots/audit-report.txt` — последний результат (125 проверок, 0 отказов на момент архивации).
- `design-comparison.md`, `edition-model.md`, `research-catalog.md` — дизайн-исследование, модель данных и источники.

Рекомендуемый следующий этап — отдельный «right-panel-only» пилот на одной статье: новый изолированный Astro-компонент/остров, включённый через существующий reader chrome. Сначала доказать, что страница и родная мобильная навигация не меняются; затем обсуждать подключение через общий шаблон статей.
