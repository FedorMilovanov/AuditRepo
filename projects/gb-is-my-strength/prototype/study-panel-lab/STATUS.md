## 3. Что действительно работает

- **Живой трёхзонный прототип** на реальной статье: левое оглавление / центр-статья / правое поле «На полях». Запущен в Arena Preview.
- **Реальный текст и стили:** Lora, Cormorant Garamond, Source Sans 3, токены сайта, оригинальные `.bref`, `.fn-marker`, `.summary-card`, карточка автора, хлебные крошки, изображения.
- **Hover → click → pin:** предпросмотр текста стиха/определения у слова; клик открывает дословный материал в «Разборе» без ухода со страницы; `Shift+клик` или кнопка закрепляют.
- **Писание:**prev/next по 181 уникальной ссылке, текст из аппарата статьи, раскрываемые реальные соседние стихи из локального корпуса, «как автор использует этот текст» с дословными фрагментами и переходами к абзацам, ссылки «рядом в этом абзаце», переход к тексту.
- **Понятия:** 14 терминов словаря, компактный hover, полное определение/`detail`, где в статье, близкие по разделу словаря, переход к абзацу.
- **Автоследование** только в ленте «У этого абзаца»; кнопка `следить/пауза`; при скролле не трогает «Разбор» и «Закреплено».
- **Память:** полка «Закреплено» вынесена из прокрутки, всегда видна; ляссе меняет длину по числу закреплений; сравнение двух материалов; список не заменяется автоматикой.
- **Аппарат:** «Ход статьи» с пятью дословными тезисами из «Коротко», нитью разделов и бусиной текущего раздела; «Сеть понятий» по совместной встречаемости; «Указатель» с поиском по ссылкам, понятиям, словам стихов и разделам; «Сравнение».
- **Состояния:** пустое / выбранное / закреплённое / свёрнутая лента / закрытая правая / закрытая левая / раскрытый контекст / указатель / сравнение / tablet drawer / mobile bottom-sheet.
- **Оригинальные контролы сайта:** нижний ряд левой рейки — дословные SVG из `ReaderRail.astro` (назад, меню, настройки, поделиться, PDF); поиск и настройки — из `SingleArticleCluster.astro`; кнопка озвучки — `PlayEmber.astro` с кольцом `stroke-dasharray:283`, глифом, паузой и галочкой; скорость — оригинальный `.gb-ember-expand` на пять позиций; день/ночь — `theme-icon-sun` (круг r=4.5 + восемь лучей) и `theme-icon-moon` (`M21 12.8A9 9 0 1 1 11.2 3a7 7 0 0 0 9.8 9.8z`) с морфом 180° из `css/floating-cluster.css`. Ни один путь не перерисован.
- **Реальные сноски:** 116 примечаний статьи читаются из DOM (текст, раздел, абзац, маркер); режим «Сноски и источники» с поиском по автору/книге/слову, открытие дословно, закрепление, переход к маркеру; сноски встроены в ленту «У этого абзаца» и в «Обзор раздела».
- **Обзор раздела:** реальные счётчики мест Писания, понятий и сносок; охват включает вложенные подразделы (например, «Оценка христоцентричной герменевтики» → 102 / 6 / 29), дословная цитата первого абзаца, чипы ссылок и терминов.
- **Справка по `?`, лента «В этом разделе», прогресс чтения и фильтр оглавления** по реальным заголовкам (10 пунктов, «Заключение» находится поиском).
- **Издание: статья, серия, книга.** Одна архитектура полей обслуживает все три формы. Инструмент «Издание» показывает открытую форму, три реальные формы рядом (Джон Гилл · 6 частей; Баптисты России · 10 частей; «Сердце» · 4 главы, 22 статьи, 727 минут) и честный список того, что меняется, а что обязано остаться общим. Переключатель в левом рельсе меняет **вид полей**, а не статью; подпись в шапке полей показывает `СТ` / `СЕ` / `КН`. Выбор части в серии и в книге — настоящий выбор: список из 6 / 10 / 22 реальных названий, переход к выбранной статье, строка места над заголовком («Книга · Глава I. Диагноз сердца · 1 / 22»), и этот выбор переживает перезагрузку вместе с закреплениями и темой. Книжный список сгруппирован в 4 главы, номера статей сквозные (1–22), подсказка после выбора сообщает главу и место; после перестроения списка клавиатурный фокус остаётся на выбранной строке и прокручивается выше полки. Новый инструмент выравнивается после завершения 300-мс анимации лент, а пустая полка занимает меньше места — карточка текущего издания видна целиком даже в мобильной шторке. Нижняя мобильная панель находится выше затемняющей подложки, поэтому смена темы больше не закрывает открытую шторку.
- **Уникальность серии — только токены.** `series-samizdat.css` и `series-manuscript.css` подключены дословно; лаборатория зеркалит их переменные в свои. `samizdat` даёт чернильный `#5b3a86` и газетную бумагу, `manuscript` — коричневую рукопись, геометрия полей не меняется. Проверено в светлой и тёмной теме.
- **Ленты полей: один аккордеон.** Свёрнутая лента — одна строка в 41 px: значок, название, один честный счётчик («4 сноски», «7 стихов», «чисто») и шеврон. Раскрытие ленты складывает остальные содержательные ленты («Закреплено» не участвует); свёрнутое состояние запоминается в `localStorage` рядом с темой и кеглем; кнопка в шапке полей сворачивает всё сразу. Семь инструментов — **один ряд значков** с подписью-подсказкой вместо сетки 3×2.
- **Полоска статуса в шапке.** Когда поля свёрнуты (или закрыта лента контекста), под названием раздела появляется живая строка: сколько материалов у текущего абзаца и работает ли слежение (`следит` / `пауза`) с точкой-индикатором. Нажатие раскрывает ленту «У этого абзаца» — это же путь назад, что и в эталоне.
- **Обучаемость.** При первом визите поля сами объясняют три жеста (читать / свернуть / открыть) и больше не появляются; справка `?` содержит легенду всех семи значков с объяснением и список новых клавиш (`Alt + Q`, стрелки по заголовкам лент, `Home` / `End`).
- **Клавиатура и доступность.** Заголовки лент листаются стрелками; свёртывание не выбрасывает фокус из ленты; у каждого значка есть `aria-label`, `aria-description` и `aria-controls`; контраст всех мелких подписей 5.1–9.8:1; цели 60×34 px; один общий тултип вместо семи, который не расширяет рельс и не обрезается у края панели.
- **Оглавление как аккордеон разделов.** Плоский список из 15 заголовков (533 px, три строки на пункт) заменён на 5 строк по 30 px: подпункты вложены внутрь своего раздела и раскрываются анимацией, текущий раздел раскрыт автоматически, пройденные помечены. Рельс следует за чтением и не даёт текущей строке уехать за край. Счётчик считает разделы («3 / 5»), а не заголовки. Тихий переключатель в шапке рельса убирает поиск, мета и прогресс, оставляя спокойный список.
- **Память полки.** Закрепления сохраняются в `localStorage` с ключом на форму издания (`…:pins:article|heart|…`), переживают перезагрузку, при смене формы полка меняется, а при возврате восстанавливается. Лимит 8 материалов, «Закрепить все N» в обзоре раздела ставит весь аппарат одним действием.
- **Чистка подписей и жестов.** Подписи в сети понятий больше не дублируются и не обрезаются по символу (было две «герменевтики» и «христотелич…»): сокращается прилагательное, а не существительное. Заголовок «нить рассуждения» больше не теряет брифы (line-height 1 у прописных), кнопка-«бусина» нити перестала быть эллипсом (круг внутри растянутого SVG), «часть» у каждого h3 заменена на честные «раздел / подраздел», строка «Семь инструментов» считается из реального списка. Описания инструментов и справка приведены к тому, что действительно реализовано (стрелки по шапкам лент, «/» и Ctrl/⌘ + K).
- **Точки перехвата и попадания.** Закрытая панель скорости озвучки была растянута почти на 300 px и невидимо лежала поверх статьи: клики по первым третям абзацев не доходили до текста. Теперь невидимая панель не принимает указатель и не видна ни ему, ни экранному диктору; открытая — принимает. Добавлен контракт `elementFromPoint` по трём точкам абзаца.
- **Книжная форма как книга.** Обзор издания раньше показывал состав серии, но никуда не вёл: выбрать часть было нельзя, шапка полей всегда называла раздел статьи. Теперь у каждой формы есть список реальных частей (22 статьи книги с настоящими заголовками из `heartSeriesData.ts` и `hardTextsSeriesConfig.ts`, а не slug-идентификаторы), клик по части меняет шапку: «Книга · Глава I. Диагноз сердца · 1 / 22» отдельной строкой и сам заголовок статьи ниже. Плоские серии получили id и тоже стали выбираемыми.
- **Типографика ссылок.** Ссылка на Писание была `inline-flex` и вела себя как неделимая коробка: «(» оставалась в конце строки, стих начинался со следующей. Теперь скобка и ссылка связаны в один `nowrap`-фрагмент, и все 129 пар держатся на одной строке — это проверяется геометрически.
- **Сопоставление всей полки.** Вместо двух колонок «два материала рядом» — сводка всех закреплённых материалов, сгруппированная по разделам статьи, где они действительно встречаются, плюс строка пересечений и ручная пара любых двух материалов (дословно, с указанием разделов каждого и общего раздела). Матрица «строки × столбцы» была сделана и отвергнута: в колонке 430 px номера столбцов без названий читаются хуже, чем группировка.
- **Книжная ступень.** «Глава I. Диагноз сердца · статья 1», прогресс книги считается по реальным минутам из конфига продукта, а не по числу экранов.
- **Темы и чтение:** `light / sepia / dark`, масштаб шрифта 90–130%, интерлиньяж, оригинальный пилл скоростей `[1, 1.25, 1.5, 1.75, 2]`, независимое сворачивание панелей.
- **Клавиатура и a11y:** `/` или `Ctrl/Cmd+K` → указатель, `Esc` закрывает, `Alt+1/2` панели, `[`/`]` соседние стихи, Tab-фокус, доступные имена кнопок, `scroll-padding`, `prefers-reduced-motion`, `prefers-contrast:more`.
- **Адаптив:** 1920 / 1440 / 1280 — три зоны; ≤1199 px — независимые drawer; ≤767 px — bottom-sheet. Горизонтального скролла нет ни на одной контрольной ширине.

## 4. Что честно помечено как демо / заглушка

- 🎧 **Озвучка** — встроенный `speechSynthesis` браузера, подпись `демо · синтезатор браузера`. Это **не** реальный `vosk-tts-engine` и не audio-контроллер сайта.
- 🔙 **«Назад»** не покидает песочницу; **«Поделиться»** копирует локальный URL; **«Печать»** вызывает `window.print()`.
- 🧠 Нет AI-ответов, саммари, выдуманных аргументов, «карты тезисов автора» и fake-интеграций. Нить разделов и граф понятий подписаны как **аналитическая разметка прототипа / анализ реального текста**.
- 📌 Закрепления теперь запоминаются в браузере (своя полка на каждую форму издания), но серверного/аккаунтного сохранения, синхронизации, заметок, аннотаций, избранного и highlights по-прежнему нет.
- 📖 Локальный корпус `data/bible` неполон: для части ссылок есть только аппарат статьи, для части — только реальные соседние стихи. Если текста нет, интерфейс сообщает об этом, а не подставляет выдуманный.
- 🔤 Термины подсвечиваются максимум 2 раза на слово и 1 раз на раздел — сознательно, чтобы статья не стала «ковром ссылок».
- ⚖️ «Сравнение» показывает только два дословных закреплённых материала, без интерпретации и вывода.
- 🎨 Переключатель форм издания есть (статья / серия / книга) и переключает палитры реальных серий, но закрепления и заметки ещё не разделяются по изданиям — это часть будущей синхронизации.

## 7. Как запустить заново

Из корня репозитория:

```bash
cd prototypes/study-panel-lab
npm ci --no-audit --no-fund
npm run build                         # index.html + восстановимые data/ и vendor/
npm start                             # статический сервер на 0.0.0.0:4321
# при работающем сервере:
npm run audit                         # 125 контрактов: a11y / клавиатура / адаптив / изоляция
npm run capture                       # галерея состояний + сбор JS-ошибок
```

`build.mjs` автоматически ищет корень checkout по статье-источнику и никогда не пишет в него. Если лаборатория запущена отдельно от репозитория, задайте `GB_SOURCE_ROOT`. Воспроизводимые результаты не коммитятся: `prototypes/study-panel-lab/.gitignore` исключает `node_modules/`, `index.html`, `data/` и `vendor/`.
