## Method

A route counts as quiz-enabled when its built HTML contains a quiz payload in either embedding form:
strict JSON (`"quiz": { "questions":`) or the JS object-literal form with unquoted keys
(`quiz: { questions:`) — both are emitted into `window.SITE_CONFIG`. Detection regex:
  ["']?quiz["']?\s*:\s*\{\s*["']?questions["']?\s*:
`[data-gill-v16]` presence is a literal string test on the same built file.
