# Reverify — The Legendary Poet

This folder stores significant selected current checks.

Create a reverify document when a work package or disposition needs a current source/build/browser/live decision. Do not create one merely because source `main` moved or an unrelated PR merged.

Older exact-source proofs remain evidence about their recorded anchors. They do not become a global current-state mirror.
