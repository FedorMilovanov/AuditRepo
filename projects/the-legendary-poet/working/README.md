# Working — The Legendary Poet

Use this folder for temporary verification-wave synthesis, duplicate maps, root-cause clustering and prioritization drafts.

Existing W0–W6 matrices and wave plans are preserved as historical working evidence. They do not remain globally current merely because they were once the latest synthesis.

When a new wave is completed:

- promote material causal/classification results to `../verified/`;
- append a compact result to `../verified/CLOSURE_LEDGER.md`;
- archive superseded working material when useful;
- do not rewrite the folder solely to follow a new source HEAD.
